# College Admission Chatbot

## About This Project
This is an interactive chatbot designed to help prospective students get information about college admissions. The chatbot can answer common questions about application deadlines, required documents, financial aid options, and campus visits.

## Features
- **24/7 Availability**: Get answers to your questions anytime
- **Quick Responses**: Instant information about admission processes
- **Conversation Memory**: The chat history is saved so you can refer back to previous conversations
- **User-friendly Interface**: Clean and simple design that's easy to use

## How to Use

### Installation
1. Make sure you have Node.js and npm installed on your computer
2. Clone this repository to your local machine
3. Navigate to the project directory:
   ```
   cd chat-bot/my-app
   ```
4. Install the dependencies:
   ```
   npm install
   ```

### Running the App
1. Start the development server:
   ```
   npm start
   ```
2. Open your browser and go to: http://localhost:3000

### Using the Chatbot
- Type your question in the input field at the bottom of the chat window
- Press Enter or click the send button to submit your question
- The chatbot will respond with relevant information about college admissions
- Your conversation history will be saved automatically

## Technology Used
- React.js for the user interface
- Local storage for saving chat history
- Custom AI logic for responding to user queries

## Project Structure
- `/my-app/src`: Contains the source code for the React application
- `/my-app/public`: Contains static assets and the HTML template
- `/my-app/src/components`: Contains React components for the chat interface

## Frequently Asked Questions
